员工门户 · 密码找回演示

FastAPI + SQLite(WAL) + argon2-cffi。两个 Web 进程共享同一业务库，可直接演示并发下的链接消费、旧链接作废与旧会话撤销。

功能入口

登录门户

忘记密码 / 申请找回链接

打开演示邮箱

查看我的身份（需登录）

演示参数

当前哈希人为延迟{{ delay_ms }} ms（可调，用于把 argon2 计算拉开观察交错操作）
链接有效期10 分钟
业务库存储仅存令牌 SHA-256 摘要，不存原始链接
预置账号alice / Wonderland-1
bob / Secret-2

推荐演示流程

  1. 用 alice / Wonderland-1 登录，打开“我的身份”确认会话有效。
  2. 在“找回密码”页输入 alice（或邮箱）申请链接，再到“演示邮箱”打开邮件里的链接。
  3. 把哈希延迟调到 5000ms：提交新密码后，在哈希计算期间另开窗口再次申请链接 / 登录 / 查询身份，均可立即响应。
  4. 重置成功后回到“我的身份”，原会话已被撤销，需要用新密码重新登录；旧密码登录会失败。
  5. 两个 Web 进程（端口 8001 / 8002）各开一个标签页，用同一链接同时提交，只有一个成功。
  6. 申请新链接后再用旧链接提交，即使旧链接未过期也会提示“已作废”。
  7. 在“哈希延迟与故障演示”页设置邮箱锁占用：可观察邮箱锁等待期间业务不被阻塞；占用超过 5 秒则投递失败，申请整体回滚且页面如实报错。
  8. 开启“投递失败”或“发布中进程退出”后申请一次：验证失败收尾不撤销他人申请，重启恢复后不存在“有效链接无邮件 / 可见邮件无有效链接”。
